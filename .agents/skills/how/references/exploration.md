# Exploration

Assign each explorer one distinct concern and the original question. Explorers gather facts; the primary agent owns synthesis and final judgment.

Each explorer should:

1. Find the entry point that triggers the behavior.
2. Trace the call chain and data transformations through actual implementations.
3. Read the definitions of central types, services, state, and interfaces.
4. Identify inputs, outputs, persistence, external dependencies, and failure boundaries.
5. Note behavior that is surprising or easy to misunderstand.
6. Return components found, traced flow, files read, boundaries, and open questions with file and line references.

Reconcile overlap and contradictions by checking the code. Do not paste raw explorer reports into the answer.
